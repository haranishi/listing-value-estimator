# PriceScope

出品時に商品の価値と売れやすい価格を判定する静的Webアプリです。

## 起動

`index.html` をブラウザで開くと動きます。依存パッケージはありません。

## 機能

- カテゴリ、ブランド力、購入価格、経過年数、状態、付属品、需要、限定性から価格を推定
- 推奨出品価格、早売り価格、相場中心価格、強気価格を表示
- 売れやすさスコアと査定理由を表示
- 売値を上げる改善チェックを生成
- 出品タイトルと説明文を自動生成
- 結果をクリップボードへコピー

## 今後の拡張

- メルカリ、ヤフオク、eBayなどの実売データ取得
- 画像から状態を判定するAI査定
- JAN/型番スキャン
- 出品後の閲覧数・いいね数をもとにした値下げ提案
- 複数フリマアプリへの一括出品
